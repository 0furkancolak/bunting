# ADR 0001: Record architecture decisions

- Status: Accepted

## Context
Bunting is meant to be a trustworthy, well-reasoned open source project. Contributors need to understand not only *what* the code does but *why*.

## Decision
Every significant architectural decision is recorded as a short ADR in `docs/adr/NNNN-title.md` with Status, Context, Decision and Consequences. ADRs are immutable once accepted; changes are made by superseding them.

## Consequences
A small amount of writing per decision, in exchange for durable rationale.
